# ISO/IEC 27001:2022 — ISMS, program-level (not bash-enforceable)

> **Honest framing first:** ISO 27001 is an Information Security Management
> System standard. It defines a *program* — policies, risk treatment,
> management review, internal audit, certification by an accredited body.
> No bash hook can "enforce ISO 27001". CCM does not claim to.
>
> What CCM **can** do: support the audit trail, automate the subset of
> Annex A controls that are code-checkable, and give the auditor a clean
> set of evidence artifacts.

---

## What CCM contributes

### 1. Audit trail support
- Every Claude Code session writes a ledger entry to `io/ledger/` (v3.2 Item A).
- Every hook block is logged to `io/hook-logs/` with a timestamp.
- `git log` is the change record; commit signing is recommended (see below).
- The deep-audit skill produces an audit hash committed to git per wave.

These satisfy the *evidence* dimension of multiple Annex A controls. They
do not satisfy the *control* itself.

config-level. They live in `compliance/CONTROLS.md` (your project's file)
or in your infrastructure repo, not here.

### 3. Recommended additions for ISO posture

If you're pursuing certification or audit readiness:

- **Sign your commits.** `git commit -S` + GPG keys. Several Annex A controls
  (8.29, 8.30, 5.17) benefit from non-repudiation on changes.
- **Tag releases.** Annex A 8.32 (Change management) wants reviewable releases.
- **Pin deploy artifacts.** Image digests, not tags, in production manifests.
- **Document your ISMS in `compliance/CONTROLS.md`.** This is the artifact the
  auditor will ask for. CCM is the secure-development-lifecycle evidence;
  CONTROLS.md is everything else.

## Severity ladder (skill output for ISO)

The `/arib-check-compliance iso27001` skill outputs an alignment report,
not a pass/fail. Sample output:

```markdown
# ISO 27001 alignment — <project> — <date>

## Automated controls (machine-verified)
- 5.17  Authentication information   ✓ secrets-block hook active
- 8.8   Vulnerability management     ✓ arib-check-deps clean
- 8.12  Data leakage prevention      ✓ PII-log hook active
- 8.15  Logging                      ⚠ no retention period declared
- 8.24  Cryptography                 ⚠ MD5 detected in src/legacy/

## Manual controls (require human evidence)
- 5.7   Threat intelligence          → CONTROLS.md missing this row
- 5.10  Acceptable use policy        → CONTROLS.md missing this row
- ...

## Verdict
ALIGNMENT-LEVEL: partial
NEXT STEP: complete CONTROLS.md and re-run.
```

The skill never says "ISO 27001 compliant". It says "alignment level: X".
That's the honest framing.
