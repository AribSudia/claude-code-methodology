# Obsidian Bridge — read-only view over CCM memory

> **Status:** optional, read-only. CCM skills remain the **sole** authority for memory
> writes (Golden Rule 2.3). This bridge adds a *view*, never a second memory store —
> the dual-state problem CCM exists to prevent.

## What it is

Point an [Obsidian](https://obsidian.md) vault at this project so you can **browse,
search, and visualize** CCM's existing memory — without changing how memory is written.
Obsidian gives you a graph view of decisions, backlinks between ADRs, and full-text
search across session notes. It reads the same markdown CCM already maintains; it writes
nothing back.

## Setup (1 minute, entirely on your machine)

1. In Obsidian: **Open folder as vault** → select this project root (or just `memory/`).
2. Recommended: include `architecture/DECISIONS.md` and `architecture/` in the vault so
   ADRs and constraints show up in the graph.
3. Treat the vault as **read-only**: do not edit memory files in Obsidian. To change
   memory, use CCM (`/arib-session-end`, the wave skills, etc.) so the freshness gate
   (`validate-coherence.sh` §8, ADR-028) and git stay the source of truth.

## Optional: wikilinks for richer backlinks

CCM memory uses plain references like `ADR-019`. If you want Obsidian's backlink graph to
light up, you may add `[[ADR-019]]`-style wikilinks **in on-demand files only**
(`architecture/DECISIONS.md`, `change_log.md`, topic notes). They are inert plain text in
Claude Code and active links in Obsidian — zero cost, additive value.

> **Do NOT add wikilinks to the always-on files** (`project_status.md`,
> `session_notes.md`). They load every session and the always-on token budget has only
> ~100 tokens of headroom (8K ceiling, CI-enforced). Keep the always-on handoff lean.

## What this bridge deliberately is NOT

- **Not a second memory system.** No writes from Obsidian; CCM is the only writer.
- **Not required.** Plain Claude Code works fully without Obsidian; this is a human-side
  reading convenience.
- **Not a live dependency.** Nothing in CCM checks for or breaks without Obsidian.
